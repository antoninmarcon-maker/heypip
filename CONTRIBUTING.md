# Contributing

Thanks for helping Pip.

- **Bugs and ideas:** open an issue with the template. For a bug, say your macOS version, your Mac (Apple silicon or Intel,
  notch or not), the call app and whether you use headphones.
- **Code:** read [AGENTS.md](AGENTS.md) first (map of the code, how to build and check). One change per pull request.
  Build with no error and no warning (`bash build.sh`), and say in the PR how you checked it.
- **Strings:** every UI string lives in `Sources/L10n.swift`, in English and French.
- **Privacy is a feature.** Pull requests that send audio, text or usage data anywhere will not be merged.
